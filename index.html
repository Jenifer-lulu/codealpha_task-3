SMART DUSTBIN – AFFORDABLE & INTELLIGENT WASTE MANAGEMENT

Hackathon Project | IoT & Sustainability

An affordable and intelligent waste management system designed to improve segregation and collection at both household and municipal levels.
Key Features:

  • Household Smart Dustbin: Low-cost (₹400–₹500) bin with moisture, metal, and fill-level sensors for wet, dry, and recyclable waste segregation.

  • Municipal Smart Dustbin: IoT-enabled large-capacity bins with GPS, weight, and fill-level sensors for real-time monitoring and optimized collection routes.
  • Mobile App & Dashboard: Provides user guidance, notifications, disposal history, rewards, and municipal visibility for efficient planning.
Impact:

  • Promotes responsible disposal habits at home.

  • Prevents overflowing public bins with real-time alerts.

  • Improves recycling rates by reducing contamination.

  • Enables data-driven municipal planning and cleaner cities.

Future Scope:

  • AI-based waste classification.

  • Computer vision for automatic identification.

  • Solar-powered bins with compaction.

  • Predictive analytics for smarter collection.

DIGITAL HEALTH RECORD MANAGEMENT SYSTEM FOR MIGRANT WORKERS IN KERALA, DESIGNED TO ALIGN WITH SUSTAINABLE DEVELOPMENT GOALS.

Hackathon: Smart India Hackathon 2025 | Theme: MedTech / HealthTech

A secure, multilingual platform designed to manage healthcare records for migrant workers in Kerala. The system enables workers to access their medical history using Aadhaar + mobile login, while doctors and hospitals can update records in real time.
Key Features:

  • Centralized, cloud-based health record storage with AES encryption.

  • Multilingual support (Malayalam, Hindi, Bengali, Odia, Tamil).

  • Offline sync for remote areas with poor connectivity.

  • AI-powered predictive alerts for chronic illness risks.

  • Integration with Kerala’s eHealth initiatives and government schemes.

Tech Stack:

  • Frontend: React.js / Flutter

  • Backend: Node.js / Django REST API

  • Database: PostgreSQL / MongoDB

  • Hosting: AWS / NIC Cloud

Impact:

  • Ensures healthcare continuity for migrant workers.

  • Reduces errors from missing records.

  • Supports early detection of chronic diseases.
